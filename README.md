# ICT Project 2026

## Local website
Open `index.html` directly in Chrome/Edge.

The main HTML file contains the original CSS and JavaScript inline so the design also works when the project is opened from a ZIP/virtual ZIP path where relative CSS/JS files may not load correctly.

The original external copies are kept in:
- `css/style.css`
- `js/script.js`

Images are in `photos/`.
